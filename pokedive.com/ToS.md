# PokéDive (pokedive.com) — Terms & Guidelines Summary

## Source Checked

- https://pokedive.com/ (game homepage) — no terms-of-service, rules, or script-use policy found on the page.
- https://pokedive.org/terms/ — independent fan guide's Terms of Use (not the game operator). States the game is provided "as-is" and that cheating can close an account; defers game-account rules to the game publisher.

## Findings

**No explicit script/userscript-use policy was found for pokedive.com.** The game site does not publish dedicated guidelines about scripts, automation, bots, userscripts, or browser extensions.

The closest available statement comes from the independent guide's terms, which quote the developer's position that cheating can result in account closure. Because this guide explicitly notes it cannot enforce or amend the publisher's account rules, the governing rules for the game itself remain with the PokéDive developer.

## Guideline for Scripts in This Folder

Until explicit terms are located, scripts created or maintained in this `pokedive.com/` folder should **avoid anything that could be considered cheating**, including but not limited to:

- Aimbot or auto-aim assistance
- Unlimited health, mana, stamina, or energy
- Unlimited money, currency, or duplicated items
- Speed hacks, teleportation, or movement manipulation
- Automation that plays the game on the user's behalf (fully automated combat, farming, or progression)
- Any feature that gives an unfair advantage over other players

Permitted script types generally include quality-of-life UI helpers that do not automate gameplay or alter game mechanics (e.g., skill detail displays, UI readability improvements, informational overlays).
